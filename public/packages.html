Packages

Two npm libraries power the app. Install them in your own project — or open the playground.

Each ships .mjs, .cjs, and TypeScript types.

Give a date → feast, tune, Coptic calendar fields, and katamaros refs (vespers, matins, liturgy). 

npm install coptic-readings
import { CopticReadings } from 'coptic-readings';

const day = new CopticReadings(new Date(2026, 3, 12));
console.log(day.feast);
console.log(day.readingReference.ref?.liturgy);
npm · coptic-readings →

Give a citation string → English and Arabic verse text. Pass refs from coptic-readings straight in. 

npm install bible-citation-text
import { getBibleText } from 'bible-citation-text';

const text = await getBibleText('John 20:1-18', {
  langs: ['en', 'ar'],
});
console.log(text.en);
